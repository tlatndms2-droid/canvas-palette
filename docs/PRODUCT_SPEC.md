# Product specification

Canvas Palette provides a three-stage workflow: collect Canvas assets, organize them in workspace palettes, and reuse them across canvases. Its four first-class item types are Card, Markdown, Image, and Group. Text scraps and direct memos become Cards. A Canvas Node context menu offers two intentional collection destinations: Mini Palette for review or direct saving to a selected Side Palette Workspace.

The Side Palette is a formal workspace-specific organizer. Mini Palette is a global hub with separate Collect and Storage tabs. Storage uses independent docked left control, main asset, and right preview panes.
